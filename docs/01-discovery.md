# Етап 1. Discovery Phase

DebtNote

## 1. Ідея

Десктопний застосунок на Qt для обліку особистих боргів між знайомими / друзями: кому винен ти і хто винен тобі. Баланс розраховується автоматично, дані зберігаються локально в SQLite.

## 2. Міні-пітч

**Проблема:** дрібні борги між знайомими записують у нотатках або тримають у пам'яті, тому їх забувають, виникають суперечки, а загальної картини немає.

**Для кого:** для всіх, хто часто позичає гроші чи дає в борг і хоче простий облік без реєстрації та хмари.

**Цінність:** відкрив застосунок і одразу бачиш, хто скільки винен, а до кожного запису можна прикріпити підтвердження (фото чека, скріншот переписки).

## 3. Аналіз аналогів

|                         | Splitwise                                                            | Мобільні трекери боргів                        | Нотатки / Excel             |
| ----------------------- | -------------------------------------------------------------------- | ---------------------------------------------- | --------------------------- |
| Платформа               | Web, мобільні                                                        | Мобільні                                       | Будь-яка                    |
| Акаунт / хмара          | Так                                                                  | Залежить від застосунку                        | Ні                          |
| Авторозрахунок балансу  | Так                                                                  | Так                                            | Лише через власні формули   |
| Підтвердження до запису | Обмежено                                                             | Не скрізь                                      | Окремо, вручну              |
| Недолік                 | Орієнтований на групові витрати, для разових боргів надто громіздкий | Прив'язка до телефона, реклама, платні функції | Немає структури, все вручну |

**Ніша:** локальний десктопний трекер особистих боргів з автоматичним балансом і вкладеннями до кожного платежу, без реєстрації.

## 4. Чому буде зручно

- Усе локально (SQLite), без акаунта та інтернету.
- Швидкий ввід боргу: контакт, сума, напрямок задається окремим перерахуванням.
- Баланс по кожному контакту та загальний рахується автоматично.
- Чеки й скріншоти прикріплені до платежів, а не лежать окремо.

## 5. Архітектурні переваги ООП

- Інкапсуляція - сутності `Contact`, `Payment`, `Attachment` самі гарантують коректність своїх даних.

- Розділення шарів (domain / data / UI) - бізнес-логіка не залежить від інтерфейсу, його можна замінити без змін ядра.

- Баланс як похідне значення: не зберігається, а обчислюється з платежів, тому немає розсинхронізації.

- Qt: сигнали та слоти для оновлення UI, дерево об'єктів Qt і розумні вказівники для пам'яті.
